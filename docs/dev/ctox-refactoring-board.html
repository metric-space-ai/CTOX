Umgebungsfallen

Jede hat mindestens einmal Arbeit gekostet. Vor dem Schreiben eines Auftrags zu lesen.

Nach einem CAS-Commit trägt der Arbeitsbaum noch die alten DateienHEAD zeigt die neue Fassung, der Arbeitsbaum die alte — der nächste Commit aus diesem Checkout nimmt alles zurück, inklusive gelöschter neuer Dateien. Fremde Änderungen als Patch herausheben, git checkout HEAD -- <pfade>, Patch mit --3way wieder auflegen.
Index-Diff-Pflicht vor commit-treeEin leerer Commit entsteht lautlos, wenn die Staging-Schleife nichts geschrieben hat. Immer git diff-index --cached --name-only zählen und bei 0 abbrechen.
.git/index.lock kann verwaisen0 Bytes, kein Prozess, und trotzdem blockiert sie stundenlang jedes schreibende Git-Kommando — für alle Sitzungen im selben Checkout. Vor dem Entfernen nachweisen, dass kein echter git-Prozess läuft.
