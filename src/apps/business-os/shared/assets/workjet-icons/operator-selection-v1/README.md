# Workjet operator icon selection v1

These raster assets are the exact images embedded in the operator-approved
34-app desktop preview. `manifest.json` records the selected candidate and the
SHA-256 of every original image.

They are raster reference assets, not SVG reconstructions. Do not rename them
to `.svg` or represent them as vector artwork. Production SVG promotion remains
subject to the Workjet Icon Studio fidelity and provenance gates.
